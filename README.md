# Damage Monitor
This mod monitors and provides detailed information on the damage dealt to visible ships.  
The damages against non-spotted ships will not be tracked.

![image](https://github.com/user-attachments/assets/950183b1-1c25-44ed-82f6-7816f4ab1867)

[TTaro Team Panel](../../../TTaroTeamPanel) allows you to view the information of dead players via the tooltip.

![image](https://github.com/user-attachments/assets/a08683db-d5fe-4ec3-baff-6477e7ea717f)


# Install
1. Download a zip.
2. Unzip the archive and you'll get `gui`, `PnFMods`, `ModSchemas` folders, and `PnFModsLoader.py`.
3. Move them to `(wows)/bin/(latest_number)/res_mods/`. So the path will look like `res_mods/PnFModsLoader.py`, etc.
4. Done!

# Requirements
You must install the following in order to use the mod.
- [TTaro Mod Config](../../../TTaroModUtils)

# Note on `ModSchemas/`

> [!WARNING]
> These files are generated by my own config tool. Do not edit them, and do not copy one
> into another mod: the `id` inside names the player's settings file, so a reused `id` makes
> the framework refuse **both** mods' settings. Trouble from an edited or copied schema is
> not a bug in my mods.
